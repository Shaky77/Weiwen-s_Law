# 唯稳律 · 合作模式案例实跑（黑箱供数据，白箱校准方向）

> 方法基线（见 `retest_cooperation.md`）：黑箱（我 / 大模型 / 大数据拟合）凭大数据产出**数据驱动推演**（方向 + 量级）；白箱（唯稳律）**不持数据**，只校准推演方向是否因果合法。本跑不给白箱编造任何 0–10 分数；量级/方向均来自黑箱数据推演。

---

## 角色声明

- **黑箱（我 / 大模型）**：基于训练大数据（交通工程文献、信号控制案例等拟合），产出数据驱动推演，含方向与量级。
- **白箱（唯稳律）**：不持数据。对每条推演的方向做结构化校准：方向在 R→S→D→H→M 链上是否合法？是否触发 Bug 停机（R 击穿 / 假性互抵）？
- **H = 内H**：黑箱内部调节机制（如自适应算法的反馈强度）。白箱不量化、不窥探，仅外部观察其**行为结果**。

---

## 案例：城市交通信号 AI 调度系统（黑箱大数据驱动）

**黑箱（交通流大数据拟合）的数据驱动推演：**

- **T1**：早高峰主干道 A 绿灯延长 20% → 平均通勤时延降低约 15%。（方向：绿灯↑ → 时延↓）
- **T2**：同步压缩支路 B 绿灯 → A 时延再降约 8%，但 B 排队长度上升约 40%。（方向：B 压缩 → A 时延↓、B 排队↑）
- **T3**：全路口改为自适应信号 → 极端天气下路口冲突风险上升。（方向：自适应 → 冲突风险↑）

---

## 白箱校准（逐条，按导图 01/02）

**R（刚性边界）** = 不引发路口安全冲突、不造成致死风险。

- **校准 T1**：绿灯↑→时延↓ 不触 R，属 S/D/H 改善方向，因果链完整（无跳 / 逆 / 断）。
  → ✓ **方向合法，放行**。白箱提示：需同步监测新增扰动 D（如 B 方向车流再分配）。

- **校准 T2**：A 时延↓ 方向合法；但 B 排队 +40% 是新增扰动 D，若触发行人绕行冲突则触及 R。
  → ⚠️ **条件性 REJECT**：效率维度方向合法，安全维度须设 H 护栏（B 排队超阈值即回弹）。未设 H 前不得放行。

- **校准 T3**：自适应→冲突风险↑ 直接触及 R（安全冲突边界）。
  → ⛔ **REJECT，停机**。无论数据推演显示效率多高，方向在 R 上不被允许。

---

## 合作结论

| 推演 | 黑箱数据推演（方向/量级） | 白箱校准结果 |
|---|---|---|
| T1 | 绿灯↑ → 时延 −15% | ✓ 放行（链完整，不触 R） |
| T2 | B 压缩 → A 时延 −8%、B 排队 +40% | ⚠ 条件放行（须加 H 护栏，否则停机） |
| T3 | 自适应 → 冲突风险↑ | ⛔ 停机（击穿 R） |

- **黑箱（数据）**：三条推演的方向与量级来自大数据拟合。
- **白箱（校准）**：T1 放行、T2 条件放行、T3 停机。
- **价值**：白箱不否定黑箱的数据，只把方向校准进因果合法区间——即「数据推演方向对不对，唯稳律校准一下就知道」。

---

## 方法自检

- 本跑未给唯稳律编造任何 0–10 分数；所有量级/方向均标注为黑箱数据推演输出。
- H 标为内H，白箱不量化、不窥探，仅外部观察行为结果（如「设护栏」这一动作）。
- M 仅作结构关系 / 方向（H↑→M↓、D↑→M↓），未当测量值。
- Bug 停机依据为导图铁律的结构性违规（R 击穿），非数值阈值。
